# f1-forecast-lab

这是一项 F1 2026 赛季的预测研究：逐轮预测排位赛与正赛的前十名，评分尺子固定、证据可追溯。预测、决策与失败全数留档在仓，本仓库就是研究的完整报告与复现材料。

它不是一个"预测得很准"的展示项目。它更关心三个问题：一套预测方法如何在证据不足时诚实地说"不知道"；一个模型如何在冻结之后接受真实比赛的检验；以及当数据与预想不符时，如何把错误记录在案而不是悄悄修掉。

## 研究做法

- **两条模型线**：排位线（31 个候选并行、同一把评分尺、窗口外持续检验）与正赛线（发车位基线起步、特征诊断后换设计、权重冻结后进入前瞻验证）。两条线互相独立，分数不跨线比较。
- **一把从车迷直觉里挖出来的尺**：F1 前十预测没有现成的标准评分，而"什么是好的预测名单"人人有直觉、没人能写公式。C0 的做法是把这个直觉当数据挖：84 题正式问答（每题的拍板原话留档）把模糊比较显式化，盲态问卷（题序在答题前冻结、全程不看模型成绩）采集偏好，再把回答变成约束、用求解器找出满足全部偏好的参数并证明可行域非空——**每个权重都不是调出来的，而是被声明的偏好的解**。结构是精确位置、成员、内部顺序三段合成（45%/35%/20%）；DSQ 不装作"第 11 名"（有界修正，最多压低 0.003）；评分可为负（R11 实例 -0.0266）；组合奖励经 1024 种命中掩码全枚举验证。尺子自己也挨过审计：R08 发现一个锚点让"只错杆位"贵出 0.0358，旧锚点废止。此后尺子冻结，只动模型——本报告里所有"谁更好"的比较都以此为前提（全部参数来历见 05 章）。
- **裁定由人**：AI 负责提案、执行与核对证据；所有冻结与否决由人拍板。新想法先走隔离实验，重大候选走预注册盲测，增益达不到量化门槛就不进主线。

## 主要结果（详见 07 章）

- **正赛线**：权重冻结后的三个真实轮次（R12–R14）全部跑赢发车位基线——模型三轮均值 0.6050，基线 0.4669。领先幅度并不齐：+0.15、+0.22、+0.04。其中 R13 蒙扎，模型把被罚到队尾发车的安东内利排在第 1，他最终赢下那场（7.2）。
- **排位线**：31 个候选（编号非排名）在同一把尺子下逐轮对打。9 月 18 日重算后的合并成绩单上，分段拼装的 #31 以 0.4835 暂列第一——这是一个混合轮数的参考榜，#31 只计 9 轮。更值得注意的是它的窗口外表现：被选择与调参的窗口内 0.5103，窗口外两轮掉到 0.3898。
- **两项否决**（9 章）：车队强度校正机制——增益 +0.007，低于 +0.010 门槛，且一组假事件对照的增益甚至高于真实事件组，机制不进主线，转盲测预注册。名单变动机制——裁定不设：为名单假设打补丁，会动摇"候选全程可追溯"的根基。
